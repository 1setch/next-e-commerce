Документация проекта Next-E-Commerce
Обзор
Интернет-магазин одежды на Next.js 16 (App Router, Turbopack) с полным циклом: от просмотра товаров до оформления заказа, админ-панели, отзывов, вопросов и верификации email.

Стек технологий
Технология	                Назначение
Next.js 16	                Фреймворк (App Router, Turbopack)
TypeScript	                Типизация
MongoDB Atlas + Mongoose	База данных
Cloudinary	                Хранение изображений
Zustand	                    Управление состоянием корзины
TanStack Query	            Запросы к API с кэшированием
CSS Modules	                Стилизация
bcryptjs + jose	            Аутентификация
Nodemailer	                Отправка писем (верификация)
Vercel	                    Деплой

Основные потоки данных
Главная страница (/)
Серверный компонент вызывает dbConnect()

Product.find({}).lean() → маппинг _id, colors

Фильтрует на isNewProduct (новинки) и isBestseller (хиты)

Пробрасывает в ProductSection → ProductCard

Каталог (/catalog)
Клиентский компонент с useSearchParams() (обёрнут в Suspense)

TanStack Query → GET /api/products?category=...&page=...&sort=...&search=...&minPrice=...&maxPrice=...

API фильтрует через Mongoose: Product.find(filter).sort().skip().limit()

Фильтры меняют URL → Query перезапрашивает

Сортировка по умолчанию: Most Popular

Кнопка "Сбросить фильтры" → /catalog

Хлебные крошки показывают выбранную категорию

Карточка товара (/product/[id])
Серверный компонент: Product.findById(id).lean()

Очистка вложенных _id у colors, защита от null

Пробрасывает в клиентские компоненты

Хлебные крошки: Каталог → Категория → Название товара

Корзина
Zustand-стор cartStore с persist в localStorage

Гость: только localStorage

Авторизован: синхронизация с сервером через GET/POST /api/cart

При удалении/изменении сразу синхронизируется

После заказа clearCart() отправляет пустую корзину на сервер

Отзывы
GET /api/reviews?productId=... — загружает отзывы

POST /api/reviews — создаёт отзыв (только для купивших, проверка по orders)

Текст необязателен — можно оставить только рейтинг

После создания пересчитывает rating и reviewCount товара

Отзыв хранит userImage — аватар автора

Вопросы (FAQ)
GET /api/questions?productId=... — загружает вопросы

POST /api/questions — авторизованные от имени, гости анонимно

PUT /api/questions/[id] — админ отвечает

В админке все вопросы загружаются одним запросом (/api/admin/questions)

Аутентификация
Регистрация: POST /api/auth/register → bcrypt → users + отправка письма через Nodemailer

Верификация: GET /api/auth/verify?token=... → isVerified: true

Логин: проверяет isVerified → JWT → httpOnly cookie

Логаут: удаляет cookie + очищает корзину

Профиль: GET /api/auth/me → фото, имя; PUT → обновление

Middleware: защищает /admin/*

Админка (/admin)
Три вкладки: Products | Orders | Questions

Products: таблица с пагинацией (20 шт.), поиском, фильтром по категории, форма в модалке

Orders: список с раскрытием деталей, смена статуса (paid → shipped → delivered)

Questions: список неотвеченных сверху, поле для ответа

Промокоды
WELCOME20 (-20), FREESHIP (-15), SALE10 (-10)

Применяются в корзине, передаются в /checkout?promo=...

Скидка вычитается из доставки

Промо-бар
Изначально скрыт

Через 1 секунду появляется для гостей

Для авторизованных не показывается
